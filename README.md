# ARXA — Industrial Scenario and Real Options Platform

Private, lightweight evidence repository for a validated portfolio prototype.

## Reproduce

```bash
make setup
make test
make reproduce
make docs
```

The prototype uses synthetic machine telemetry and cost assumptions. no industrial client data or observed financial impact. Its results are technical evidence, not a claim of production deployment or client impact. Start with `docs/DOSSIER.md` and verify `artifacts/evidence-manifest.json`.
