# Internal project dossier — ARXA — Industrial Scenario and Real Options Platform

Status: technical prototype; publication and user-interpretation gates pending.

## Why this project exists

Can a transparent predictive-maintenance scenario model connect data quality, failure risk, operating cost and the option to act or defer?

## Mechanism

Rolling risk forecast, threshold policy, scenario expected-cost comparison, data-quality degradation test and a simple act-versus-defer real-option calculation.

## Evidence chain

Concept record → source map → pre-test prediction → code → unit and negative tests → deterministic result → evidence hashes → case-study draft.

## Claim boundary

The defensible claim is that a narrow, local prototype was implemented and tested on the disclosed fixture. No production, client or realized-impact claim is made.
